# ScreenCoordinator 最小任务清单

> 设计依据：`doc/detailed-design.md` 第 7.9、11 节  
> 模块目标：按流程状态展示页面、填充中文内容、控制按钮状态，并把用户意图转换为类型化信号。

## 边界

- 负责：UI 场景、主题、页面显隐、文本绑定、按钮信号、响应式布局。
- 不负责：答案判定、奖励、装配规则、Tween。
- 前置模块：内容 DTO 和 `GameState` 契约；可用固定数据独立测试。

## 最小任务

- [x] **SC-001 建立全局 Theme。** 引入许可清晰的简体中文字体，设置标题、正文、按钮和状态样式。验证：字体许可证记入来源夹具，常用及铁路术语无缺字。
- [x] **SC-002 创建 StartView。** 包含标题、玩法说明、“开始体验”和“退出”。验证：两个按钮分别只发出一次意图信号。
- [x] **SC-003 创建 QuizView 基础布局。** 包含进度、题目、四个选项和反馈卡片。验证：固定问题可完整显示。
- [x] **SC-004 实现答题初始/错误状态。** 四个选项可点击；错误时只显示固定错误文案。验证：错误后选项保持可用。
- [x] **SC-005 实现答题正确状态。** 禁用选项，显示解析、来源三字段和“进入装配”。验证：URL 自动换行且按钮正确显隐。
- [x] **SC-006 创建 AssemblyHUD。** 显示“装配 N / 9”、零件名和操作提示。验证：忙碌时文案变为“正在安装……”。
- [x] **SC-007 创建组件完成覆盖层。** 显示组件名称和 `teaching_note`，支持第三组件较长说明。验证：牵引供电教学边界完整显示。
- [x] **SC-008 创建 EndView。** 显示祝贺文案、整车名和“退出”，不提供重开或主页按钮。验证：退出信号测试通过。
- [x] **SC-009 创建 FatalErrorView。** 显示错误编号、简短说明和退出按钮。验证：长错误摘要不会越界。
- [x] **SC-010 实现状态到视图映射。** 按详细设计表控制唯一主页面及允许覆盖层。验证：8 个状态逐项断言显隐。
- [x] **SC-011 实现内容绑定接口。** 接收题目、正确/错误反馈、装配数据、组件数据和结束数据。验证：绑定只更新视图，不改变业务对象。
- [x] **SC-012 实现响应式布局。** 使用 anchors 和 size flags 适配 1280×720、960×540 及窗口放大。验证：两种基准尺寸关键控件不越界。
- [x] **SC-013 完成 UI 回归。** 覆盖页面信号、按钮启用、中文显示、来源换行和全部状态显隐。验证：UI 场景测试全部通过，格式和 lint 通过。
