# RailCraft Demo v0.1.0-demo

发布日期：2026-07-19

## 版本定位

这是 RailCraft Demo 的首个可交付版本，用于工创赛演示、铁路知识教学流程验证和 Godot 模块化工程展示。

## 主要内容

- 9 道固定顺序铁路知识单选题；
- 错误答案保留原题并允许重试；
- 正确答案显示解析、来源机构、资料标题和 URL；
- 每题奖励一个唯一列车零件；
- 9 个零件按单链依赖完成点击吸附装配；
- 第 3、6、9 个零件分别完成一个系统级组件；
- 最终整车动画包含组件强调、车灯、受电弓和轮对反馈；
- 完整中文 UI、离线字体、致命错误页和退出清理；
- 数据驱动内容、资产契约校验和可替换低多边形模型；
- Windows x64 导出、质量 CI 和构建 artifact。

## 已知限制

- 模型为原创低多边形教学资产，不对应特定真实车型的精确工程结构；
- 不包含账号、网络服务、存档、排行榜、多人、自由镜头、暂停、跳题、重开和音频；
- GitHub hosted Windows runner 的交互式桌面诊断可能在图形初始化前异常退出，实际 Windows 运行结果优先于该 CI 环境诊断。

## 升级建议

后续版本可替换为正式工业设计模型、增加音效和讲解旁白、补充可视化安装说明，并将题库与模型资产继续保持数据驱动和模块化。
