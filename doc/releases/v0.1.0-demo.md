# RailCraft Demo v0.1.0-demo

发布日期：2026-07-19

## 版本定位

首个可交付演示版本，用于工创赛展示、铁路知识教学流程验证和 Godot 模块化工程展示。

## 主要内容

- 9 道固定顺序铁路知识单选题，错误可重试，正确后显示解析与来源；
- 每题奖励一个唯一零件，9 个零件按连续单链依赖完成装配；
- 第 3、6、9 个零件完成三个系统级组件；
- 三阶段吸附、组件强调与整车终局动画；
- 原创低多边形动车组模型、完整中文 UI 和离线字体；
- 启动内容/资产校验、致命错误页、退出清理和最小窗口限制；
- 固定工具链、124 个自动化测试、Windows x64 导出及可追溯验收证据。

## 验证结果

- 格式、lint、pre-commit、Godot 导入、主场景加载：通过；
- GUT：124/124 通过，1598 个断言；
- Windows x64 导出、PE、大小、SHA-256、ZIP 和导出包启动检查：通过；
- 20 项 Windows GUI 验收：通过，详见 [`../acceptance/windows-v0.1.0-demo.md`](../acceptance/windows-v0.1.0-demo.md)。

## 已知限制

- 模型为原创低多边形教学资产，不对应特定真实车型的精确工程结构；
- 首版不包含账号、网络服务、存档、排行榜、多人、自由镜头、暂停、跳题、重开和音频；
- CI 的交互式 GUI 启动与截图属于诊断步骤，仓库内真实 Windows GUI 证据作为界面验收记录。
