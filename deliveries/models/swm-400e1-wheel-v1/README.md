## 适用性判断

该文件可以进入模型资产管线，当前只能登记为“候选车轮源模型”。内嵌预览能够证明外形类别，仍无法证明其轮径、轮缘型面、轮毂孔、质量属性和接口尺寸符合 SWM-400E1。

Unity 不直接导入 `.SLDPRT`。运行时资产统一采用优化后的 `.fbx`；原始 CAD、交换格式和 Unity 资产分层保存，后续替换时保持稳定的 `part_id` 与装配锚点。

车轮在首版玩法中归入“轮对轴箱模块”，单个车轮不作为独立拖放步骤。这样可保持子系统级装配范围，并给后续替换完整轮对、轴箱和一系悬挂模型留出空间。

## 需要成员补交的最小资料

1. 从原 SolidWorks 环境导出的 `STEP AP242 (.step)` 或 Parasolid (`.x_t`) 文件。
2. 单位确认：毫米。
3. 车轮名义直径、轮宽、轮毂孔径或对应工程图。
4. 坐标约定：车轴中心为原点，车轴方向为局部 `X` 轴，车辆前进方向为局部 `Z` 轴，局部 `Y` 轴向上。
5. 模型身份说明：通用铁路车轮、参考件，或已按 SWM-400E1 适配。
6. 若成员能够直接导出游戏网格，再补交三角化 `.fbx`；保留法线，不合并到转向架总成。

收到交换格式后再进行尺寸核对、拓扑清理、减面、UV、碰撞体和 Unity 装配锚点验收。
