## 检查结论

OpenCascade 成功读取 1 个根装配、1991 个实体、2025 个壳和 47674 个 CAD 面。模型包含车轮、轴承、轴箱弹簧、抗蛇行减振器、盘形制动缸、中央悬挂和牵引拉杆等完整客车转向架结构。

原始包围尺寸约为 3161.6 × 3518.7 × 1007.3 mm。该模型适合用作 CW-200K 客车转向架的教学参考；它不代表 CR400AF、复兴号或 SWM-400E1 工程模型。

## 运行时转换

转换链：

1. `Tools/CAD/convert_cw200k_step.py` 通过 OpenCascade XCAF 读取装配名称和层级，并以毫米转米导出 GLB。
2. Blender 删除螺钉、螺母、垫片和挡圈等高密度小件。
3. 对大型 CAD 网格分级减面，保留车轮、构架、悬挂、制动和牵引轮廓。
4. 设置钢、轮钢、弹簧、制动、橡胶和牵引六类材质。
5. 将原点归一到转向架中心与轨面，并导出 Unity FBX。
