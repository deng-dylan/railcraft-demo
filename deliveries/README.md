# RailCraft 交付登记

`deliveries/` 用来登记外部资料、成员交付和评审输入，Git 只跟踪说明、清单、校验值和必要的审计记录。

## 当前分区

- `content/`：题库、文案或教学内容交付。
- `external/`：外部 Demo、第三方包和隔离包装记录。
- `models/`：模型与工程文件的交付登记、许可说明和校验值。
- `process/`：流程稿、装配步骤和工艺相关交付。
- `research/`：调研资料和结构分析交付。

## 维护规则

- 原始大文件和未经授权再分发的包保持在 `release/` 或外部存储，并继续忽略。
- 每个交付目录至少保留来源、日期、责任人、许可边界和 SHA-256。
- 进入主线应用前，先把交付内容转成源码、清单或可复核证据，再按对应批次提交到 `apps/`、`docs/` 或 `Artifacts/`。
