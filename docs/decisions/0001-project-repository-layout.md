# ADR-0001：项目总仓库与应用工程的边界

- 状态：已采纳（历史结构，2026-09-04 由当前基线替代）
- 日期：2026-07-21

## 背景

团队需要在同一处管理赛项资料、产品想法、技术评审、外部 Demo 和实际可运行的应用工程。Godot Demo 已有独立提交历史，项目总仓库也已完成初始目录整理。

## 决策

项目总仓库曾统一保存项目级资料、原型治理记录和多套应用源码。该决定适用于历史阶段；
第一版白盒之前的运行时 Demo 已退休，当前仓库只维护 Unity ThirdPerson 主线。原型来源和
评审记录继续保留，原始包放在本地/私有交付目录。

## 结果

- 项目资料能够与应用代码一起被检索、评审和追溯。
- 历史 Godot 工程的提交仍可通过 Git tag 和日期归档追溯。
- GOOD2 等跨引擎方案只作为评审背景，不进入当前构建链路。
- 当前克隆只需要取得 Unity 主线和当前基线；旧原型按需从归档恢复。

## 约束

- 不在主 Demo 中嵌入第二套游戏引擎或运行时。
- 原始交付包不进入 Git 历史；其版本、校验值和来源记录写入 `deliveries/`。
- 需要将原型能力纳入主线时，按主工程的数据、许可和测试标准重新实现。
