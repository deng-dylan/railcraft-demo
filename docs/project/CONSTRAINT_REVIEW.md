## 已移除的旧硬约束

- 具体锁定 `CR400AF`、`SWM-400E1` 或 `SWT-400E1`；
- 题目数量、工位数量和零件数量必须相等；
- 旧版 48 题、15 步、无存档、无音频、无成绩等 v0.1 限制；
- 固定视角 Unity v0.1、Godot Demo 和外部原型继续作为日常入口；
- 用预览图或模型名称推断工程尺寸、接口和检修参数。

## 当前新增门禁

- 资产身份必须标记为 `展示风格`、`通用教学件` 或 `车型专用工程件`；
- 题库必须有来源、审核状态和核心/备用标记；
- 视觉批次必须同时记录 LOD、碰撞、材质、纹理、单位和哈希；
- 旧文档若与本页冲突，以当前基线和状态文件为准，并在变更记录中写明冲突处理。
