# 项目基线资料说明

这里保存项目启动阶段的需求、设计、实施提示词和模块任务，内容保留原始上下文，便于追溯决策来源。

2026-07-21 起，项目总仓库采用以下映射：

| 历史文件中的路径 | 当前路径 |
| --- | --- |
| `doc/` | `docs/project/`（项目级基线资料）或 `apps/railcraft-godot/doc/`（Godot 应用交付文档） |
| `demo/` | `apps/railcraft-godot/` |

历史描述中的“外层仓库不纳入 Demo”反映当时的实施边界。当前总仓库已通过 Git 子模块保留这个边界：项目资料与 Godot 应用有独立提交历史和发布节奏。
