## 2. 产品身份

RailCraft 是面向竞赛演示的通用高速动车组工程场景模拟。玩家在车间内完成知识确认、
材料准备、子总成装配、落车、教学调试、检验和复测。外观可以采用复兴号、和谐号常见的
流线、窗带和色彩语言，项目不把当前展示网格声明为 CR400AF、SWM-400E1 或任何其他
具体型号的正式工程复刻。

车型身份分为三层：

1. **展示风格**：用于车体外观、灯光和场景气质，只承担视觉表达。
2. **通用教学件**：用于说明轮对、构架、悬挂、制动和落车关系，可采用低模或参考件。
3. **车型专用工程件**：只有在责任人、来源、单位、尺寸、接口和授权全部核验后才可启用，
   并且必须单独标注适用车型。

当前 CW-200K 转向架和队员提供的车体属于展示/通用教学层，不能在文案中写成
CR400AF/SWM-400E1 工程件。

## 3. 交互规模决定

题库数量不再决定零件数量。当前标准工单采用 **5 个玩家材料包 + 1 个调试/检验流程模块**，
14 个 `PartId` 仅作为内部配方、视觉分解和旧存档兼容层：

| 玩家交互单元 | 内部子部件 | 作用 |
| --- | --- | --- |
| 轮对轴箱材料包 | 车轴、车轮、轴承 | 走行和载荷传递基础；一次领取、一次装配 |
| 构架与制动/牵引材料包 | 制动装置、牵引拉杆、传感器座 | 构架上的安装与力传递接口 |
| 一系悬挂材料包 | 弹性元件、定位元件、一系减振元件 | 轮对—构架之间的悬挂关系 |
| 二系悬挂材料包 | 空气弹簧、高度控制、二系减振元件 | 构架—车体之间的隔振和高度保持 |
| 车体落车材料包 | 车体、中央牵引装置 | 车体落车和连接关系 |
| 调试与检验 | 教学故障、处理、检验、复测 | 过程模块，不虚构车型专用零件 |

14 个 ID 保留在域模型中，便于旧存档、配方和逐件显隐兼容；玩家界面和题目工位按材料包
组织。每个材料包的知识门禁由 2 道核心题组成，答完后原子解锁包内子件，领取和安装各只
发生一次。传感器座、定位元件和高度控制元件是包内语义子件，拥有明确工程来源后再替换
几何；它们不占用独立题目工位。

## 4. 题库策略

用户提供的 `50道选择+30道判断.doc` 是唯一原始题库来源。正文实际为 50 道单选和 8 道
判断，共 58 道；缺少的 22 道判断题不自行补写。

题目、工程知识和奖励流程分开维护：

- 58 题完整保留，用作题库、备用题和知识图鉴；
- 首个 Art Alpha 主流程目标为 10 道核心门禁题（每个材料包 2 题）；
- 题目可重复用于同一模块的变体与重试，取消“每题必须对应一个独立零件”的约束；
- 题目元数据至少包含 `topic`、`workPackage`、`module`、`isCore`、`source`、`reviewStatus`；
- 含未经核验数值的题目进入 `pending-review`，不会作为工程标准展示；
- 题库、核心精选、材料包配方和旧奖励路由分别编号；版本写入快照，改题不改变旧存档中的 PartId。

建议暂缓作为核心题的内容包括：动平衡 `≤5 g·m`、绝缘电阻 `≥100 MΩ`、空气弹簧保压
时间/压降，以及地铁架修年限/里程。它们需要车型、标准或工艺文件来源才能进入正式内容。

## 5. 当前可用资产与缺口

### 已可用于内部视觉生产

- 工人角色、Idle/Walk/Run 动画和 UI 反馈音效；
- Kenney Factory Kit 工位模块、Train Kit 维修轨道与平板车；
- PBR 桥式起重机、集装箱、变电站和 ArtStationIndustrial 背景层；
- 队员车体展示 FBX、CW-200K 参考转向架及牵引拉杆拆分；
- 程序化厂房、地面、标牌、流程灯光和完整 ThirdPerson 场景。

### 仍需补齐或核验

1. 传感器座、定位元件、高度控制元件和明确的二系空气弹簧几何；
2. 定位夹具、升降台、吊具、扭矩工具和检验仪表；
3. 成品地板/墙体/门窗/磨损贴花，以及厂区外景、堆场、车辆远景、天空和雾效；
4. 真实 HMI 测试柜、线缆、警示牌和可交互工业道具；
5. 所有正式网格的 LOD、简化碰撞体、PBR 材质、纹理和尺寸验收；
6. 第三方资产的许可证、署名和竞赛提交再分发范围；
7. 目标机 1920×1080 性能、加载时间、显存和异机断网走查。

免费候选可以用于观察和内部参考，进入提交包前必须完成许可与来源登记。无授权的盗版、
破解、去水印资源不进入项目。

## 6. 当前验收门禁

每个可交付批次至少要同时满足：

1. 代码、场景、资产、题库版本和文档指向同一批次；
2. Unity EditMode、Windows 构建和成品烟测有可复核证据；
3. 视觉资产注明身份层级、来源、单位、LOD、碰撞和许可状态；
4. 未核验工程数值不会被 UI 写成作业标准；
5. 旧存档兼容策略和变更说明已登记；
6. 当前状态文件和变更日志已更新。
