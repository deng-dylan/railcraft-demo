# AnimationCoordinator 最小任务清单

> 设计依据：`doc/detailed-design.md` 第 7.8、10 节  
> 模块目标：串行播放吸附、组件和整车动画，管理交互锁，并以带 ID 信号报告完成或失败。

## 边界

- 负责：Tween、忙碌状态、表现节点临时变化、完成信号和清理。
- 不负责：安装提交、题号推进、组件判定。
- 前置模块：`AssemblyView` 的公开接口和最小动画夹具。

## 最小任务

- [ ] **AC-001 创建协调器和忙碌锁。** 实现 `is_busy()` 与单动画占用规则。验证：忙碌时第二个播放请求被拒绝。
- [ ] **AC-002 实现吸附前置检查。** 获取 actor 和目标，缺失时发出 `part_snap_failed(part_id, reason)`。验证：失败后忙碌状态已清除。
- [ ] **AC-003 实现吸附第一阶段。** 0.15 秒放大并抬升。验证：缩短时长测试断言中间 Transform。
- [ ] **AC-004 实现吸附主移动。** 0.60 秒插值位置、旋转和缩放到目标。验证：结束误差在容差内。
- [ ] **AC-005 实现吸附回弹和收尾。** 0.15 秒回弹，调用视觉提交并发出一次完成信号。验证：最终 Transform 精确且点击禁用。
- [ ] **AC-006 实现组件完成动画。** 高亮指定组件、轻微上浮回位并显示完成请求。验证：完成后材质和 Transform 恢复。
- [ ] **AC-007 实现组件停留时间。** 普通说明至少 2.8 秒，第三组件教学说明至少 4 秒。验证：使用可覆盖测试时长避免真实等待。
- [ ] **AC-008 实现最终组件依次高亮。** 按配方顺序强调三个组件。验证：触发顺序固定且无随机性。
- [ ] **AC-009 实现整车反馈。** 依次点亮车灯、升起受电弓并轻微转动车轮。验证：三项终态与场景节点一致。
- [ ] **AC-010 实现取消与降级清理。** `cancel_all_for_shutdown()` 清理 Tween、临时材质和交互锁；非关键视觉错误仍发完成信号。验证：每个退出点无残留。
- [ ] **AC-011 完成动画回归。** 覆盖吸附成功/失败、重复请求、三个组件和最终动画。验证：动画集成测试全部通过，格式和 lint 通过。

## 模块完成标准

- [ ] 同一时刻最多一个进度动画；
- [ ] 吸附完成和失败信号均携带正确 `part_id`；
- [ ] 动画只修改表现节点；
- [ ] 所有成功、失败和退出路径都释放交互锁；
- [ ] 流程单测可用假动画替代本模块；
- [ ] 更新 [`progress.md`](progress.md) 中模块任务数和完成状态。
