# AssemblyView 最小任务清单

> 设计依据：`doc/detailed-design.md` 第 7.10、9、17 节  
> 模块目标：管理待安装零件、安装目标、视觉提示和已安装实例，向流程层只发送 `part_id` 点击事件。

## 边界

- 负责：`PartActor`、`TrainAssemblyRoot`、零件实例、目标、提示、组件视觉归组。
- 不负责：安装是否合法、领域提交、动画时序、页面状态。
- 前置模块：内容 DTO；动画模块可稍后接入。

## 最小任务

- [ ] **VW-001 创建 PartActor 场景契约。** 建立 `VisualRoot`、`ClickArea`、`CollisionShape3D` 和类型化脚本。验证：场景可 headless 实例化。
- [ ] **VW-002 实现 PartActor 点击信号。** 注入 `part_id`，仅在启用状态响应鼠标单击。验证：启用时发出一次，禁用时不发出。
- [ ] **VW-003 创建 TrainAssemblyRoot。** 建立三个组件容器、`SnapTargets`、灯光和最终动画锚点。验证：节点路径与详细设计一致。
- [ ] **VW-004 创建 AssemblyView 空壳。** 缓存预览锚点、列车根和组件容器，定义公开接口与 `part_clicked` 信号。验证：缺节点时返回明确错误。
- [ ] **VW-005 实现 prepare_part。** 从 `model_scene_path` 实例化一个待安装零件，应用预览变换并注入 ID。验证：重复准备同一零件不会重复实例化。
- [ ] **VW-006 实现目标查找。** 按 `snap_target_path` 获取 `Marker3D` 并应用目标微调 Transform。验证：合法和缺失目标测试通过。
- [ ] **VW-007 实现发光目标提示。** 创建无碰撞视觉副本并递归应用 Compatibility 可用的发光覆盖材质。验证：提示可创建、脉动和清理。
- [ ] **VW-008 实现视觉安装提交。** 把零件归入对应组件容器、设置精确目标变换并禁用点击。验证：安装后映射和父节点正确。
- [ ] **VW-009 实现组件高亮接口。** 只影响指定组件的已安装 Mesh，清理后恢复原材质。验证：其他组件材质不变。
- [ ] **VW-010 实现交互总开关。** `set_part_interaction_enabled()` 同步控制当前待安装 actor。验证：动画锁定期间点击无信号。
- [ ] **VW-011 实现表现错误清理。** 准备失败、目标缺失和中止安装时释放预览与提示，不污染下一次准备。验证：连续失败后合法零件仍可展示。
- [ ] **VW-012 制作车体外壳占位场景。** 包含流线型头部、长条车身和车窗区域。验证：场景契约和目标吸附测试通过。
- [ ] **VW-013 制作客室车门占位场景。** 使用可辨认矩形车门模块。验证：契约、点击和目标位置测试通过。
- [ ] **VW-014 制作车钩缓冲装置占位场景。** 使用端部连接结构。验证：契约和组件归组测试通过。
- [ ] **VW-015 制作转向架构架占位场景。** 使用车体下方深色框架。验证：契约和位置测试通过。
- [ ] **VW-016 制作轮对占位场景。** 使用车轴及左右车轮。验证：轮节点可供最终动画旋转。
- [ ] **VW-017 制作制动装置占位场景。** 使用靠近车轮的盘或夹钳抽象件。验证：契约和位置测试通过。
- [ ] **VW-018 制作受电弓占位场景。** 使用可折叠单臂或菱形结构。验证：提供最终升弓动画节点。
- [ ] **VW-019 制作牵引变压变流单元占位场景。** 使用车下箱体教学抽象件。验证：契约和位置测试通过。
- [ ] **VW-020 制作牵引电机占位场景。** 使用转向架附近圆柱或箱体。验证：契约和第三组件归组测试通过。
- [ ] **VW-021 完成 9 零件表现回归。** 按数据顺序准备并视觉安装全部零件，检查映射、目标、组件容器和资源释放。验证：AssemblyView 与资产契约测试全部通过，格式和 lint 通过。

## 模块完成标准

- [ ] 9 个零件均符合统一 `PartActor` 契约；
- [ ] 模型场景可通过 JSON 路径替换；
- [ ] 点击、提示、目标和组件归组均有测试；
- [ ] 模块不判断奖励和安装合法性；
- [ ] 960×540 与 1280×720 固定视角下关键对象可见；
- [ ] 更新 [`progress.md`](progress.md) 中模块任务数和完成状态。
