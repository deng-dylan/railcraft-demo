# RailCraft 原型归档说明

`prototypes/` 当前不承载可运行主线。第一版白盒之前的 Ren'Py 和外部 Godot 包装已退休，
原始交付仍按 `deliveries/external/**/release/` 的来源与许可登记保存在本地/私有存储。

如需复核旧方案：

1. 先阅读 `docs/reviews/` 对应评审记录；
2. 核对 `deliveries/external/` 的 SHA-256 和许可边界；
3. 在临时目录重新解压原始包，完成独立审计；
4. 不把旧原型复制回当前主线，也不把它们当作当前产品基线。

当前体验、开发和发行入口位于 [Unity ThirdPerson 主线](../railcraft-unity/README.md)。
