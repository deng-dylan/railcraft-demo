# RailCraft Demo 运行说明

## 系统要求

- Windows 10 或 Windows 11 x64；
- 支持 OpenGL 3.3 的显卡与驱动；
- 最低显示区域 960×540，推荐 1280×720 或更高；
- 约 250 MB 可用磁盘空间。

体验过程全程离线，不需要安装 Godot、Python 或其他开发工具。程序不创建存档，也不发送使用数据。

## 启动

1. 下载 `RailCraft-Demo-windows-x64.zip`。
2. 将 ZIP 完整解压到可写的普通文件夹；请勿直接在压缩包预览窗口中启动。
3. 双击 `RailCraft-Demo.exe`。
4. 在开始页选择“开始体验”，依次完成 9 道题和 9 次零件安装。

窗口可以放大或缩小，最小尺寸为 960×540。首次运行时，如果 Windows 显示来源提示，请先确认文件来自本项目的私有 GitHub Release，再选择继续运行。

## 操作与退出

- 使用鼠标左键选择答案、进入装配和点击发光零件。
- 回答错误后可以继续选择；回答正确后会显示解析与资料来源。
- 每道题只奖励一个固定零件，按提示完成当前零件安装后进入下一题。
- 可在开始页和结束页点击“退出”。窗口标题栏关闭按钮也会结束程序。

## 常见问题

### 双击后没有窗口

确认 ZIP 已完整解压，并更新显卡驱动。程序使用 Godot Compatibility 渲染器，仍需要可用的 OpenGL 3.3 驱动。可尝试把解压目录移动到路径较短的位置后再次启动。

### 中文显示为方框

发布包内嵌 Noto Sans SC 字体。出现缺字通常表示下载或解压不完整，请重新下载 ZIP 并完整解压。

### 界面内容被截断

将窗口调整到至少 960×540，或使用最大化按钮。Windows 显示缩放较高时，建议保持窗口最大化。

### 想重新体验

首版完成后只提供退出。关闭程序并再次启动即可从第一题开始；程序不会保留上次进度。

### 来源链接无法点击

链接作为教学资料文本展示，程序不会发起网络请求。需要查阅时可手动复制到浏览器。
