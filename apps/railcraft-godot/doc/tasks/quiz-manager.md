# QuizManager 最小任务清单

> 设计依据：`doc/detailed-design.md` 第 6.4、6.5、7.4 节  
> 模块目标：维护当前题目、作答结果和装配后的题号推进，不产生奖励或 UI 副作用。

## 边界

- 负责：题目顺序、当前索引、当前题已解决标志、作答结果。
- 不负责：奖励、装配、页面展示、文件读取。
- 前置模块：`ContentRepository` 提供 `QuestionData`；单测可直接构造 DTO。

## 最小任务

- [x] **QM-001 创建 AnswerResult。** 定义 `WRONG`、`CORRECT_FIRST_TIME`、`ALREADY_SOLVED`、`INVALID_OPTION`、`NOT_STARTED`。验证：枚举和值对象构造测试通过。
- [x] **QM-002 实现 configure/reset。** 注入题目副本并重置索引、开始和解决状态。验证：重复配置不会保留旧进度。
- [x] **QM-003 实现 start。** 有题目时返回第 1 题并进入开始状态；空题集返回明确失败结果。验证：起始边界测试通过。
- [x] **QM-004 实现 get_current_question。** 开始前、正常状态和越界状态行为明确。验证：查询不改变内部状态。
- [x] **QM-005 实现错误作答。** 有效错误索引返回 `WRONG`，保持题号且允许重试。验证：连续错误测试通过。
- [x] **QM-006 实现首次正确作答。** 返回 `CORRECT_FIRST_TIME` 并锁定当前题。验证：不自动推进题号。
- [x] **QM-007 实现重复和非法作答保护。** 正确后再答返回 `ALREADY_SOLVED`；负数或大于 3 返回 `INVALID_OPTION`。验证：状态不被修改。
- [x] **QM-008 实现装配后推进。** 仅已解决题可调用 `advance_after_assembly()`；普通题进入下一题，末题返回无下一题。验证：未解决、正常和末题测试通过。
- [x] **QM-009 完成答题回归。** 使用两题夹具覆盖开始、错后再答、正确锁定、推进和重置。验证：`test_quiz_manager.gd` 全部通过，格式和 lint 通过。
