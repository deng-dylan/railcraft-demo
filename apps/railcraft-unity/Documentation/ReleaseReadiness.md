# RailCraft v0.2 当前进度与发行判断

- 评估日期：2026-08-21
- 评估对象：Unity 第三人称“标准工单 RC-EMU-01”主线
- 当前分支：`codex/coherent-training-flow`
- 建议版本定位：`v0.2.0-preview.1` / 竞赛演示候选版

## 结论

当前版本已经具备完整可运行的 Windows 演示闭环，可以用于团队内测、阶段汇报、
竞赛评审预演和小范围体验。源码、场景、测试、Windows Player 与自动冒烟已经形成
同一批次证据。

公开发布或作为工程实训成品交付前，仍需完成工程知识来源复核、模型与第三方资源授权
复核、版本与发行包元数据、异机人工走查四项发行工作。当前内容只能表达教学流程和
结构示范，不应作为动车组真实作业指导、扭矩标准、配合公差或检修结论使用。

本批适合先推送功能分支并作为发行候选保存。完成“发行前必须完成”清单后，再创建
正式标签、GitHub Release 和对外下载包。

## 本批已完成

- 主菜单收敛为单一标准实训，扩展车型继续保留存档兼容和开发者烟测入口。
- 工厂重排为“知识确认与材料准备 → 子总成与转向架装配 → 落车、调试与检验”三段工艺区。
- 本轮详细装配一套代表性转向架，第二套以配套生产线供件方式进入落车成品。
- 落车完成态显示带两套转向架、车窗、腰线和统一材质的动力中间车。
- 首次调试失败明确标记为教学故障注入，完成处理、检验和复测后结算。
- 普通入口、HUD、工位提示、反馈文案和结算文案统一为实训语义。
- 当前批次 EditMode 199/199 通过，Windows 构建 0 warning / 0 error，成品自动冒烟成功。

## 发行前必须完成

1. **工程内容复核**：为结构、工艺、扭矩、公差、检修和智能运维知识建立逐条来源表，
   标明教材、论文或标准编号；没有可靠依据的具体参数应删除、泛化或标记为待审核。
2. **资产与授权复核**：确认转向架、车体、复兴号模型和第三方 Factory Kit 的来源、
   授权范围、署名与再分发条件；示范件继续保留醒目标识。
3. **发行元数据**：将 Unity `bundleVersion` 从历史 `0.1.0` 更新为正式发行号，补齐
   Release Notes、第三方声明、许可证与下载包说明。
4. **干净发行包**：从目标提交执行干净构建，压缩完整 `Builds/Whitebox/`，生成 ZIP
   与可执行文件 SHA-256；避免只交付单个 EXE。
5. **异机人工走查**：在另一台 Windows 10/11 电脑断网启动，完整完成一次标准工单，
   检查中文字体、分辨率、显卡兼容、存档、暂停、重玩和退出。
